# ADR-005 — SonarCloud pour l'analyse qualite
- **Date :** 2026-11-20
- **Statut :** Acceptee
- **Proprietaire :** MF

## Decision
SonarCloud gratuit avec sonar.qualitygate.wait=true.

## Quality gate
- 0 issue Blocker ou Critical
- Duplication < 3 %
- Couverture nouvelles lignes >= 80 %
- Notes A (maintenabilite, fiabilite, securite)

## Date de revue
Sprint 1.
